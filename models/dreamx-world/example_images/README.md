# DreamX-World example images

Upload any image in this directory through `set_image`. The three files are
unmodified copies from the public DreamX-World demo at revision
[`a1f4c6e`](https://github.com/AMAP-ML/DreamX-World/tree/a1f4c6e5e45600718e5236955f2e0702e53fc275/demo).
The adapter resizes an upload to the model's 1280×704 inference resolution.
